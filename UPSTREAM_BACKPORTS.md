## Deliberately excluded

- Source revert of the aftermarket battery guards: preserve local no-data checks and the nonzero FCC divisor check instead of removing all protections.
- EEVDF/CASS, FIE/thermal-pressure redesign, zcomp/zsmalloc redesign, and critical-task reclaim bypass: these require separate dependency and runtime evaluation.
- KernelSU/NoMount replacements and unrelated tuning of CPU shares, network buffer sizes, fast charging limits, or display calibration.
- Fixes already present, source changes explicitly reverted without an applicable final replacement, and inactive AW8697/CFQ tuning.

## Validation

- CPUFreq, camera request-manager, BPF core/filter and compaction objects: compiled successfully with the existing munch configuration and ZyC Clang 16.
- KGSL, fuel gauge and the two munch SMB5 objects: compiled successfully with the same configuration.
- Full MIUI/HyperOS Image build: PASS (`out/arch/arm64/boot/Image`), ZyC Clang 16, existing munch KSU+SUSFS configuration. Rebuilt after applying the active camera-xiaomi mirror; all 31 changed C files compile, including an explicit generic-camera compatibility build.
- Full AOSP Image build: PASS (`out/backport-aosp/arch/arm64/boot/Image`) with XIAOMI_MIUI and the proprietary AOSP-disabled hooks disabled. Rebuilt after the active camera mirror; all 31 changed C files compile. This uses a separate output configuration derived from the existing munch configuration, not a flashable release package.
- Whitespace: `git diff --check` PASS. Kernel checkpatch: 0 errors, 0 warnings across 1119 patch lines.
- MIUI/AOSP modpost diagnostics: duplicate exports of cpu_frequency/gpu_mem_total and an init-section reference from ksu_hide_bootloader_init() to ksu_register_feature_handler(). All corresponding tracepoint and KernelSU files are unchanged relative to their baseline repositories; these warnings are not introduced by the selected patches.
- Fresh AOSP output initially encountered pre-existing generated UAPI wrappers in the source tree, which made Kbuild/VPATH skip generating output-local asm/types.h. Seeding the unchanged ARM64 UAPI wrappers into the separate output directory resolved setup without changing source or removing existing build artifacts.
- A read-only ADB smoke check was performed on the flashed munch device on 2026-11-14 around 22:19–22:25 WIB: boot/root, CPU profiles, BPF startup, ZRAM and TCP settings were readable, and no fatal kernel/GPU/display signature was found in the available logs. Bypass charging was enabled, so normal charging power was not tested. Camera, controlled sleep/wake, load/stress and full backport regression testing remain unverified. See the local diagnostic report in `ki_logs_20261114_2219/SUMMARY.md` (ignored diagnostic artifacts).
- No flashable ZIP has been packaged or flashed by this update.

Build logs, checksums, source patch and machine-readable validation are saved locally under `out/backport-validation/` (ignored build artifacts). Image headers were checked for ARM64 magic. Both output trees contain up-to-date objects for all 31 changed C files. The AOSP Image-only build also prints two nonfatal DTS-directory lookup messages; DTBs were not built or packaged in this task.
